## Objetivo:
 Desarrollar una propuesta básica para organizar tareas académicas, permitiendo registrar actividades, asignar prioridades y visualizar progreso.

 Tareas:
 1. Definir el problema a resolver.
 2. Establecer funcionalidades principales (mínimo 4).
 3. Definir roles del sistema (usuarios).
 4. Describir el flujo de uso.
 5. Consolidar documento final.

 ## Entorno simulado:
 - Chat
 - Issues
 - Documento compartido

 ## Evento:
 Un integrante pierde conexión y se debe redistribuir el trabajo.

 ## Entregables:
 - Registro de comunicación
 - Lista de tareas completadas
 - Documento final consolidado
